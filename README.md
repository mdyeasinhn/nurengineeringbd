# Nur Engineering Solution

Machine parts catalog and technical service website for an EEE-led supply desk in Bangladesh.

Layout follows the company wireframe: top contact bar, logo + brand header, category navigation, search, left category sidebar, hero slider, and product/service grids.

## Stack

- Next.js 15 (App Router) + TypeScript + Tailwind CSS 4
- MongoDB (Mongoose) for products, categories, services, banners, inquiries

## Setup

```bash
cp .env.example .env.local
npm install
npm run seed
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
